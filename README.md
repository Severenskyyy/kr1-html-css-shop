# SoundShop — интернет-магазин наушников и колонок

## Контрольная работа №1

Тема: «HTML и CSS: разработка многостраничного сайта».

В проекте реализован многостраничный HTML/CSS-сайт интернет-магазина наушников и портативных колонок «SoundShop». На сайте есть главная страница, каталог, карточка товара, форма заявки и страница контактов.

## Ссылка на опубликованный проект

GitHub Pages: https://severenskyyy.github.io/kr1-html-css-shop/

Репозиторий: https://github.com/Severenskyyy/kr1-html-css-shop

## Структура проекта

```
kr1-html-css-shop/
├── index.html        — главная страница
├── catalog.html      — каталог товаров
├── product.html      — карточка товара
├── order.html        — оформление заявки
├── contacts.html     — контакты
├── css/
│   └── style.css     — общий файл стилей
├── js/
│   └── main.js       — открытие и закрытие модального окна
├── images/           — изображения товаров
├── README.md
└── .gitignore
```

## Используемые технологии

- HTML5 (семантическая разметка)
- CSS3 (CSS-переменные, Flexbox, CSS Grid, позиционирование)
- БЭМ-именование классов
- JavaScript — только для открытия и закрытия модального окна `<dialog>`
- Git, GitHub, GitHub Pages

## Как посмотреть проект

1. Открыть ссылку на GitHub Pages (указана выше).
2. Или скачать репозиторий и открыть файл `index.html` в браузере.

## Обязательные страницы

| Страница | Содержание |
|---|---|
| `index.html` | hero-блок, преимущества, популярные товары |
| `catalog.html` | категории, статический блок фильтров, карточки товаров |
| `product.html` | изображение, описание, цена, таблица характеристик, кнопка заявки, модальное окно «Условия доставки» |
| `order.html` | форма оформления заявки |
| `contacts.html` | контактная информация и ссылка на форму заявки |
